💬 WhatsApp Templates Setup Guide

Copy these 6 templates into Meta Business Manager → WhatsApp → Message Templates. Once approved (~24–48h), proactive reminders and invoices will deliver reliably to patients regardless of the 24-hour session window.

1
Open Meta BM business.facebook.com
2
Go to Templates WhatsApp → Message Templates
3
Create Template Paste body text below
4
Submit for Review Approved in 24–48h
5
Go Live Status → Active ✓

  • Submit templates for review — typically approved within 24–48 hours
  • Set 8 new Railway environment variables listed above
  • Run 3 SQL schema files in Supabase SQL Editor (in order v9 → v10 → v11)
  • Push latest code to GitHub (git push — need fresh personal access token)
  • Railway auto-deploys on push — watch logs for startup errors
  • Test /signup page at your Railway URL: https://…/signup
  • Test a reminder by booking an appointment 2 minutes from now and checking scheduler logs
